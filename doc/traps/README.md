# The trap index

Status: **standing** — one row per trap, through which every citation by number resolves. What a
round reads up front is [`every-round.md`](every-round.md), the ten rows the records cite most
(`tools/state.sh traps` counts the citations and the share they carry), copied from this table
verbatim — a row changed here is changed there, and `--test every_round_rows` holds the copy; this table is opened when
a contract names a trap, or when a group file's position column bites (ADR 1639).

**A row is a lookup key, not the trap.** Read the position column against what this round is about
to do; where a row bites, open the group file its last column names and read the trap in full —
the incident, the evidence and the argument are there, and they are why anybody believes the rule.
Nothing is decided from a row alone (ADR 1036): a trap is an incident with a rule attached, and the
group files keep all of it (`CLAUDE.md`, "Where knowledge lives").

**Every trap keeps its number**, because `crates/`, `tools/`, the ledger and the ADRs cite them by
number and an ADR is not edited to follow a file that moved underneath it (ADR 0232 §2). A trap
merged into another, or demoted to a habit, keeps its row, and the row says where its incident now
lives — under the survivor as a `####` heading of its own number, or in `doc/habits/measuring.md`;
an incident is relocated, never deleted (`doc/reviews/1018-what-retiring-a-trap-would-cost.md`).
`grep -n 'merged into\|\*habits\*' doc/traps/README.md` lists the moved ones, and
`cargo test -p conformance --test traps` holds every row to its entry and every entry to its row.

The group files, and the round each is for:

| file | the round it is for |
|---|---|
| [`pixels-and-rasterisers.md`](pixels-and-rasterisers.md) | can change a pixel — the interpreter's marks, any rasteriser, colour, a cross-backend scene |
| [`oracle-and-references.md`](oracle-and-references.md) | reads a verdict, diagnoses a page, invokes another renderer, or moves a tolerance |
| [`parsers-and-streams.md`](parsers-and-streams.md) | touches `pdf-syntax`, a filter, a font program, an image codec, or decides what to do with input it cannot fully handle |
| [`the-interactive-loop.md`](the-interactive-loop.md) | turns a press into a command, converts between the page's space, the display list's and the raster's, answers the core about a render, or waits on a toolkit's loop |
| [`instruments-and-reports.md`](instruments-and-reports.md) | runs a gate, believes a number, adds a report, sweeps for a defect, or puts a process under a limit |

Each group file also carries the standing facts about its own area, beside the traps about the same
machinery, and those are not indexed here.
