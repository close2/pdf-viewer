# 1823 — A deep image of any colour count is a JPX file, and a sign is kept

Session 1823, a "clause" round in batch 123 (slot 1, two agents: the second finished a handover); 2026-10-27. ADRs 2480 and 2481; Q689 unused (no word of the owner's was needed).

**Contract.** §12.5.6.23's `JPXDecode` refusal narrows to a component past the decoder's twenty-four bits: ITU-T T.801 Annex M's JPX file, with its Reader Requirements box (M.11.1) and the source's colour specification box (M.11.7.2), for any other colour count; and a signed component's sign kept on redaction.

**Premises.** The brief's hypothesis "a signed component loses its negative samples to the decoder's clamp" did not hold. The decoder adds 2^(p-1) to every component whatever its `Ssiz` says, and flipping the sign bit of a written file changed no delivered integer. The negative samples are not lost; **the statement that the component was signed is**, because the output was written unsigned. ISO 32000-2 §8.9.5.2 gives the domain 0 to 2^n - 1 and no map from a signed value (§7.4.8, §7.4.10 silent), so the offset is a documented choice (ADR 2481). "One check and one offset at one site" held for the redaction, but the writer needed a JPX container. A second premise broke late: round 1825 found the decoder reads `cdef` type 1 as opacity and rejects type 2, which the sandbox's decoder tolerates, so the redaction types its channel plain (ADR 2480).

**What was built.** `pdf-jpx-write`: `Space`, `ColourBox`, `file()`, the `rreq` box, the sign bits in `Ssiz`, `ihdr` and `bpcc`; `jp2()` output byte for byte as before. `pdf-transform`: `OwnRaster` carries the signs and the source's first colour box; `written_as_jpx()` is "deeper than sixteen, or any component signed", which **changes the output form of a signed image of sixteen bits or fewer from `FlateDecode` to JPEG 2000** (ADR 2481). The `jpx_write` fuzz target draws CMYK, vendor spaces and signs; its first crash was the decoder's four-channel limit on a vendor space with opacity, and the target now stays inside it.

**Rows.** §12.5.6.23 stays `departed`, on the calculator function (ADR 1363) and a component past twenty-four bits; its note, `doc/todo/65`, `doc/state-of-play.md` and `doc/crate-map.md` say so.
