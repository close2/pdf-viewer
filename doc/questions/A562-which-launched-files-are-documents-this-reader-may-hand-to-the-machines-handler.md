Reading: both recommendations adopted as the question states them, quoted and attributed:

1. **The classification is the line** — a file is a program, refused at every level, where its permissions let it execute (or it cannot be read), where it begins with an ELF, PE, Mach-O or `#!` signature, or where its name ends in one of the fourteen executable extensions; everything else is a document. It errs towards *program* on every test, so its failure is a document refused with a sentence; the stricter alternative — a media-type allow-list by content sniffing — has no clause behind it and costs a detector this tree does not have. It is the same shape as the launcher-name test ADR 0104 set for URI schemes: a claim the file makes about itself, checked before it reaches anything that can act.
2. **`refuse` is the default, until the level has a menu entry in every window, then `ask`** — A254's own shape, because a question no window can put is a refusal anyway; making `ask` the default before the menus exist would change nothing a person can answer and would put silent refusals behind a question's name.
