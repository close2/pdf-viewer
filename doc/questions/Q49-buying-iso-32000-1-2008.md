# Q49 — Should the project buy ISO 32000-1:2008, PDF/A-2's base document?

Source: `doc/pdf-a-conversion-limits.md` §1.2, found while writing the limitation catalogue from
the newly readable ISO 19005-2.
Status: **retired, not answered** — the owner obtained the document on 2026-09-07, so the
question as posed has no occasion left. No `A49` is owed. What replaced it is work rather than a
decision, and it is written down under "The premise changed" below.

## Why it needs the owner

ISO 19005-2 §5.1 makes a conforming file one that adheres to **all requirements of ISO 32000-1**
as modified by part 2, and §6.7.2.1 pulls in ISO 32000-1:2008 §14.8 wholesale for Level A. This
tree carries **ISO 32000-2**: that is what `doc/md/` holds, what the conformance ledger is written
against and what every doc comment in `crates/` cites. Where the two editions agree — most of the
file format — reading the requirement in ISO 32000-2 gives the same answer. Where they differ,
a PDF/A-2 verdict would be citing a clause the part does not name, and principle 5 does not permit
pretending otherwise.

**It does not block anything if PDF/A-4 comes first** (Q46): part 4's base is ISO 32000-2, the
edition this tree owns.

## The premise changed on 2026-09-07

**The owner obtained it, for nothing.** Adobe publishes ISO 32000-1:2008 without charge and it is
now `doc/PDF32000_2008.pdf`, gitignored like every other specification PDF here
(`doc/third-party-data.md`). So the question as posed — *should the project buy it* — no longer
needs an answer, and what is left of it is smaller and is a matter of work rather than money:
which of `crates/pdf-archive`'s part 2 rows now cite the edition part 2 actually names, and
whether `Part::Two`'s wrong-edition caveat can be retired outright or only narrowed.

Two things it unparked immediately, both recorded where they act: Annex A's operator summary,
which three rounds had written down as a table nobody holds, and §9.7.5.2's predefined CMap
table, which ISO 32000-2 dropped and which PDF Association issue #77 is parked on.

## What the tree does meanwhile

`doc/pdf-a-conversion-limits.md` §1.2 records the gap; §7's discipline would report any
requirement read from the wrong edition as such rather than as checked.

## What is left, and it is not a question

`doc/md/ISO_32000-1_2008.md` is the prepared text (`tools/spec-md.py`, 756 pages). The remaining
work is to read part 2's rows against the edition part 2 actually names, and to find out whether
`Part::Two`'s wrong-edition caveat can be retired outright or only narrowed. Neither needs the
owner.

**The recommendation this file used to carry — buy it if and when PDF/A-2 becomes a target — is
kept here deliberately rather than deleted.** It was the right answer to the question that was
asked, and it was overtaken by an acquisition rather than by an argument; a reader who finds only
the conclusion learns less than one who finds what the reasoning was before the facts moved.
