This is a representation audit, not a new function or colour-conversion algorithm review. §7.3.9 (physical p.48 / printed p.33) defines the null object and states that an undefined indirect reference is null and a null-valued dictionary entry is equivalent to omission. §7.3.10 (physical p.49 / printed p.34) repeats the undefined-reference point and says any object value may be direct or indirect unless a specific rule says otherwise, with equivalent semantics. The numeric arrays and scalar values selected here are ordinary function and colour-space entries, and I found no local direct-only exception.

For sampled functions, Table 38 (physical pp.139–140 / printed pp.124–125) defines Domain/Range pairs, and Type 0 Table 39 (physical pp.140–141 / printed pp.125–126) defines sample-grid entries including Encode and Decode. §7.10.2 spans physical pp.140–142 / printed pp.125–127. `function.rs::pairs` and `numbers` call `Document::get_key` for a dictionary entry and `Document::resolve` for each array member. `parse_sampled` uses the same route for Size, Encode, and Decode. Existing function tests assert useful direct-form interpolation behavior, but the inspected tests do not compare direct and indirect arrays or referenced numeric members. The scratch Type 0 regression uses exact xrefs and literal samples `[0,255]`: at input 0.5 with Encode `[0,1]`, the normalized interpolated sample is 0.5; Decode `[0,1]` therefore yields 0.5. Its Range `[-1,1]` makes a missing Decode application yield 0, so the oracle is discriminating. The PDF's indirect version makes Domain, Range, Encode, Decode arrays and their numeric elements indirect. This validates one representative Type 0 path, not Type 2/3 or every nested reference shape.

For CalGray, §8.6.5.2/Table 62 (physical p.201 / printed p.186) requires WhitePoint and allows Gamma with default 1. `parse_cal_gray` uses `get_key` for Gamma; `entries::numbers` resolves WhitePoint and each of its components. Current CalGray conversion tests exercise gamma and white-point arithmetic, but the searched PDF parser tests state those fields directly. The draft compares an indirect WhitePoint array with indirect numeric components and indirect Gamma against a direct control. With D50 WhitePoint and Gamma 2, gray 0.5 has linear luminance 0.25; IEC sRGB encoding yields ≈0.53709873 per channel. The expected neutral is independent of the two parser outputs and the comparison checks conversion through the public `to_rgb` consumer.
