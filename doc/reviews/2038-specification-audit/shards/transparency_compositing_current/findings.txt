The current assertion record for the assigned behavior is substantial but distributed. `transparency.rs` checks separate `CA`/`ca` stroke/fill routing and opaque defaults; `transparency_groups.rs` contains pixel-level isolation, non-isolation, knockout, alpha-is-shape, alpha constants and page-group-space controls; `group_constructions.rs` has direct raster constructions with expected values. The clause-anchored group tests include one-composite-versus-object-wise output and nonisolated-versus-isolated differences. The suite's assertions are more useful than mode-name coverage alone because they compare pixels against formulas or controls. Cross-backend agreement remains corroborating behavior, not an independent standards oracle.

Ledger assertions that deserve restrained interpretation: §11.3.3's cited soft-mask closed-form test proves a Normal weighted-average case, not the general blend-overlap terms; the blend-mode direct values prove mode functions but not arbitrary alpha composition. The §11.3.4 tests exercise several DeviceGray/CalGray/CalRGB/ICCBased/CMYK spaces and page/group routes. The ledger already states that exact conversion into one-component DeviceGray/CalGray blending spaces is a chosen route (ADR 0790), not a fully specified numeric requirement. Page-group tests cover explicit group color spaces and output conversion; this shard did not assert the default device for every runtime environment because §11.4.7 intentionally keys it to actual/assumed/simulated output device. §11.6.4.4's cited tests cover the two constants, AIS and application to a group result; full operator-by-operator state reachability was outside this review.

Selected ADR review is in `decisions.json`. ADR 0047's local nonseparable arithmetic and literal independent expected values are sound for B(Cb,Cs), while cross-backend agreement alone is insufficient as an oracle. ADR 0237 does not claim that its optimized Normal-result path stores §11.4.4's general accumulators. It algebraically derives that, for its nonisolated/non-knockout group under Normal with unit shape/opacity at the group result, backdrop removal and re-composition collapse to `(1−w)B + wE(B)`. The CPU path uses a buffer seeded with the backdrop and an interpolation; this equivalence is bounded to those conditions, not a general group formula implementation. EC3 #688 corrects two initialization symbols in the §11.4.8 restatement (`a_g0`, `a_0` to `α_g0`, `α_0`); any literal transcription of that summary must use the corrected alpha symbols. ADRs 0251/0277 align with the source's active-space and CMYK rules; no exhaustive profile conversion review is claimed. ADR 0790 is correctly represented as a processor choice. ADR 2183 byte rounding is distinct from the real-valued standard formula.
