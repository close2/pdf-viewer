Destination arrays: cell coverage and source boundaries

The effective source is ISO 32000-2:2020 §12.3.2.1–.2 and Table 149, printed pp. 441–443 / primary PDF physical pp. 456–458. The table number is 149. A destination supplies a page, a view location, and zoom. The array's first element is an indirect page reference for ordinary/local destinations, but an integer page index into the target document for GoToR and GoToE. The §12.3.2.2 note records the embedded-GoTo correction as well as remote Go-To; the integer index is zero-based in the current model and tested target page 2 is selected by integer 2.

The table's eight forms are exercised individually in pdf-model/src/destination.rs::every_form_table_149_lists_is_read. That test is a syntax/model assertion, not proof of visual geometry. Public consumer evidence comes from viewer-core/tests/headless.rs::an_open_action_states_where_to_look_at_the_page_and_how_large and tests/destinations_residual_audit.rs. Together they supply literal scale and origin expectations for XYZ, Fit, FitH, FitV, FitR, FitB, FitBH and FitBV. The latter test distinguishes page-fit from content-box-fit using non-origin CropBox arithmetic. The parser test a_null_parameter_is_not_a_zero separates null and zoom-zero from explicit coordinate zero; the public local-navigation tests separately assert retained versus stated view values.

Table 149's /XYZ null components retain current left/top/zoom independently; zoom zero is null-equivalent. /FitH and /FitV fit page width/height, while /FitBH and /FitBV fit the content box and still transform their stated top/left operands in default user space. /FitB forms bound the content box by CropBox. Existing geometry tests use independently calculated values and matched page-versus-content controls; no additional test is warranted in this shard.

The cross-document target-index boundary is covered by viewer-core/tests/cross_document_destination_view_spec_audit.rs: local GoTo uses an indirect page reference, while GoToR and GoToE supply integer 2 and assert selected target page index 2. Direct target OpenAction and local controls establish the target's explicit XYZ geometry. Current recorded B23 is specifically the remaining view-propagation failure: after Supply, the remote and embedded routes select the correct page but show default-fit geometry rather than scale 2/origin (-80,-200). This shard does not duplicate B23 or imply the target-page-index behavior is wrong. The durable expected-failure record and current findings are authoritative for that failure.

EC3 Issue #536 is on Table 149's FitR smaller-factor instruction (physical p.457 / printed p.442); its Caret inserts “interactive processors should.” The inserted phrase precedes “use the smaller ... , centring the rectangle ...” in one sentence. I read SHOULD as applying to both smaller-factor choice and centering for FitR. The separate FitB row is unchanged and retains SHALL language. B24 records the tested implementation mismatches: qualify its FitR part as a discrepancy with a recommendation, while its FitB part remains a SHALL-level mismatch. Do not recast either as a new gap. Likewise, rotation/crop composition is in navigation_geometry_residual_current.

ADRs 0162 and 2814 remain supported for the parts their local geometry tests establish: destinations carry page/view, coordinates are transformed from default user space, nulls retain state, and FitBH/FitBV use their coordinate operands. Their corner-only FitR/FitB inference differs from Table 149; B24 already captures it, with FitR qualified as SHOULD-level by #536 and FitB remaining SHALL-level. ADRs 1227 and 0094 are not reopened for host handoff or embedded traversal; B23 is limited to loss of view when the replacement target document opens.

No new draft was created. The parser matrix, local public geometry controls, rotated-coordinate shard, and existing B23/B24 cases cover the selected array cells without adding a duplicate regression. This is not a certification of malformed-array recovery, every transform/form combination, or all native hosts.
