# Filter parameter cells: selected assertion audit

Baseline: `b901326c`. This bounded review covers selected parameter cells in Table 8 (physical pp. 55–56, printed pp. 40–41), Table 10 (physical p. 57, printed p. 42), Table 11 (physical p. 59, printed p. 44), and Table 12 (physical p. 61, printed p. 46) of `doc/ISO_32000-2_sponsored_EC3.pdf`. The table locations were checked against the actual captions and printed footers, not nearby cross-references. No substantive EC3 annotation affecting these parameter-cell rules was found in the inspected annotation context.

Table 8 / Table 10 have strong selected decoder assertions. `flate_lzw_spec_audit::table8_defaults_and_png_row_tags_reach_both_decoders` asserts literal bytes for default Predictor behavior, omitted predictor dimensions, and mixed PNG row tags under Predictor 10 through both Flate and LZW. The PNG row tags—not Predictor's exact value above 9—select None/Sub/Up row processing. Existing `filters.rs` tests assert TIFF and PNG reconstruction bytes. `lzw_full_table_audit::full_lzw_table_clear_resets_width_and_dictionary_for_both_earlychange_values` independently builds a packed stream, asserts literal decoded output after crossing the 9/10/11/12-bit boundaries, and tests EarlyChange 0, 1, and the omitted default 1. This closes an older scratch note that omitted default had not traversed the width transition; the current test does.

B54 already covers indirect numeric DecodeParms separately. Its direct controls pass, while indirect Predictor and Columns cases fail; indirect outer Filter/DecodeParms controls pass. This shard deliberately does not duplicate that gap or imply Table 8 is otherwise exhausted.

Table 11 implementation and tests cover several distinct rules: K mode selection, optional alignment, byte-padded width, Rows with EndOfBlock=false, BlackIs1 polarity, and DamagedRowsBeforeError applicability/substitution. The exact complement raster test for BlackIs1 is a strong oracle. The direct decoder test observes valid end markers, and existing model tests exercise public rendering. However, the current `ccitt_bound::end_of_block_true_ignores_a_short_rows_and_draws_the_whole_image` does not contain Group 3 RTC; it is not a valid positive fixture for EOB. The new unrun draft `drafts/ccitt_eob_rows_public_reader.rs` supplies a two-row Group 4 encoded image ending in EOFB, with `/Rows 1`, image Height 2 and a `/Rows 2` control. Literal expected black samples, exact xref, and recovery/chain-cut checks make the consumer distinction observable. Parent execution is pending; no failure is claimed until then.

The draft concerns a valid-stream Table 11 rule only. It does not settle behavior for data/Height mismatches, nor establish a mandatory reader rejection for missing EOL or malformed parameters. Likewise, the policy of drawing delivered rows while leaving the remainder unpainted and reporting a shortfall is recorded in ADR 0794 and should remain separate from normative filter behavior.

Table 12's JBIG2Globals is optional and typed as a stream of global/page-0 segments; it may be shared, and the stream remains separate even for a single referencing image. Code resolves and passes the stream. The standard worked example is covered at worker level and through a PDF integration path. The former uses structural sample checks, not a complete expected bitmap; no duplicated test was warranted. Shared-globals reuse across two public image consumers remains unreviewed here. Table 12 does not state a required reader response for a wrong-type malformed value.

Relevant ADR review is in `decisions.json`. ADR 0102/0036 cover filter stage and LZW behavior but not indirect parameter values. ADR 0392's Rows/EOB distinction is retained, with the valid EOB consumer assertion pending. ADR 1349 supports the custom CCITT decoder needed to expose line damage; this shard does not recertify all T.4/T.6 codes. ADR 0794's shortfall presentation and ADR 0454's geometry/resource policies are treated as product/policy boundaries rather than additional Table 11 MUSTs. ADR 2102 establishes JBIG2 decoder provenance, not a normative pixel oracle.

No Cargo command, Git operation, production/test/ledger edit, or nested agent was used. The sole Rust draft in this directory is unexecuted; parent runs and decides promotion. This artifact reports source/assertion review separately from pending execution and does not infer a current failure from historical logs.
