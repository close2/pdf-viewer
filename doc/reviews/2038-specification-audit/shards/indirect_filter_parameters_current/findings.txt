The assignment's shorthand named §7.3.9 for indirect representation; the primary source separates the rules. §7.3.9 is “Null object” at physical p.48 / printed p.33. The direct/indirect equivalence sentence is §7.3.10 at that same page: “Except where documented to the contrary, any object value may be a direct or an indirect reference; the semantics are equivalent.” It covers the value of an ordinary stream dictionary's /Filter and /DecodeParms and their array members, subject to a documented exception. §7.4.1 (physical pp.49–50 / printed pp.34–35) requires filters named in the stream dictionary and assigns optional parameters through DecodeParms; Table 5 at physical p.47 / printed p.32 defines the single and array forms.

The relevant exception is real and local. §7.5.8.2 (physical p.81 / printed p.66) says cross-reference stream Table 17 values are direct, array elements are direct, and encoded xref streams' Filter/DecodeParms are direct. EC3 #246 broadens the directness clause to Table 5 values and their arrays/dictionary values and bars /F; #720 adjusts which xref dictionary entries may be indirect. Those bootstrapping rules should not be generalized to ordinary stream dictionaries. `xref.rs::decode_direct` reads those xref-stream values directly. In contrast, ordinary `Document::filter_chain` uses `get_key` for the Filter value and resolves each filter-array member; `decode_parms` resolves the top-level DecodeParms and, for arrays, each entry before accepting a dictionary.

Existing assertions strongly establish the direct case: `filters.rs::each_stage_takes_its_own_entry_of_a_decodeparms_array` gives null to ASCII85 and a direct PNG predictor dictionary to Flate, then checks exact decoded samples. `lzw_full_table_audit.rs` checks EarlyChange behavior and its default with direct parameters. CCITT public tests exercise dictionary parameters directly. The JBIG2 test's indirect `/JBIG2Globals` is nested inside a direct DecodeParms dictionary and is not evidence for an indirect DecodeParms value. I found no ordinary-stream direct-versus-indirect Filter or parameter pair in the searched syntax/model test trees.
