Fixture role audit: FreeText test PDFs in `variable_text.rs` and `rich_text.rs`

The shared builders currently write object 5 to Page `/Annots` and also put `/Fields [5 0 R]` in Catalog `/AcroForm`. For the focused tests, object 5 is explicitly `/Subtype /FreeText`, not `/Widget`. That fixture therefore presents a standalone annotation as an AcroForm field as well. The result may still reach the intended FreeText code path, but it is not a clean standalone-subtype witness. The same concern applies when the seed annotation is a Link in the test that later calls `add_free_text`; the Link should not be listed as a field either.

The maintainable correction is to make fixture role explicit. In `variable_text.rs`, preserve `pdf_with` and `pdf_with_appearance` as the existing field/widget constructors. Add named `free_text_pdf` and `free_text_pdf_with_appearance` wrappers that call the existing `pdf_with_field_list` with `fields = ""`, leaving `/AcroForm /DR` intact. Convert only the identified FreeText callsites and the FreeText-specific `bordered_annotation` helper; leave the already-correct `callout_annotation` builder alone. In `rich_text.rs`, keep the existing field builder's `/Fields [5 0 R]`, factor its catalog construction through an explicit fields-list helper, and add `free_text_pdf` using an empty list while retaining /DR fonts. Convert the two FreeText tests; the remainder exercise Widget fields and stay unchanged.

The generated staged patch is `drafts/freetext_fields.patch`; `drafts/make_patch.py` reconstructs staged files and patch from the current audit-worktree sources. Staged copies are under `drafts/variable_text.rs` and `drafts/rich_text.rs` for review. No tracked file was edited and no Cargo command was run.

`callout_annotation` in variable_text.rs already uses `/Fields []` from the parent-corrected helper, so the draft preserves that working fixture. The role issue applies to remaining FreeText helpers/callers, not every fixture in those files: actual Widget forms continue using `[5 0 R]`. The test annotations are still reported/drawn through Page `/Annots`, and AcroForm default fonts remain present so the standalone FreeText `/DA` can be resolved.

Limitations: this is a fixture-validity improvement, not a claim that no-AP cases satisfy the PDF 2.0 writer AP rule. The corpus witness is not edited. Parent review and execution are pending.
