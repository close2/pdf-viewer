More importantly, the existing public viewer-host print-query test watermark_nup_consumer_audit::public_print_query_places_fixed_watermarks_inside_each_two_up_and_four_up_cell is not a pending proposal: it reaches public PrintPage output, rasterizes the stored AP and checks literal 20-point mark bounds in the chosen 2-up and 4-up cells. The older annotation_remaining_current wording that n-up geometry still needs separate coverage is stale; the later watermark audit and parent-reviewed decision inventory already record this stronger evidence. These assertions establish the model/host output geometry, not actual paper, device, or spooling behavior.

The current API offers one-, two-, and four-page sheet layouts; no page-tiling selection was found. The tiling obligation is conditional on a processor selecting tiling, so it does not imply a current failure. The primary source does not prescribe the layout grid itself; the host's 2-up/4-up coordinates are product choices tested against independent dimensions.

Page /Rotate remains a qualified interpretation. The source's B sentence refers to a scaled and rotated page, while ADR 0934 argues that ordinary annotation rotation and the NoRotate flag control page rotation. Existing FixedPrint tests rotate the annotation's own Matrix, not the page. This audit does not elevate that disagreement to a defect or invent a normative oracle; any follow-up should establish source interpretation before adding a rotated-page expected-output test.

No new test draft is warranted: current tests independently cover defaults, known media, scale cancellation and actual public n-up mark placement. Native output and conditional tiling remain outside the evidence obtained here.
