Bounded review: page transition and duration table cells

The relevant table numbers and locators are distinct. Page-object `/Dur` and `/Trans` are entries in Table 31 at physical p.121 / printed p.106. `/Dur` is the page's maximum display time in presentation mode and the entry's own default is no automatic advance; manual page advancement may happen earlier. The Table 31 rule that an absent `/Dur` prevents automatic advancement is explicit. `/Trans` identifies the visual transition to use when moving from another page to this page during a presentation. The Table 164 transition dictionary is instead at physical pp.477–478 / printed pp.462–463; it defines transition `/D`, not page `/Dur`. NOTE 2 assigns that `/D` to the transition into the page. The EXAMPLE puts the transition before the destination page's display-duration interval.

I checked the effective Table 164 rows against the current parser and assertion bodies. `/S` defaults to R; R is a no-effect replacement and ignores `/D`, while other defined styles default `/D` to one second. `/Dm` applies to Split/Blinds, `/M` to Split/Box/Fly, `/Di` to Wipe/Glitter/Fly/Cover/Uncover/Push, and `/SS` and `/B` to Fly; the implementation carries the defaults into the Transition value and the transition consumer uses them for relevant geometry. Direct tests include the clause's own Split example, R with `/D 9`, Split defaults and overrides, Wipe direction, and Fly defaults/overrides. Additional static frame tests assert source-described geometry and disclose owner-selected quantities where the standard withholds a value. The current tests do not mistake a nonexistent transition style for a defined style: an unknown name is preserved and produces no frame.
