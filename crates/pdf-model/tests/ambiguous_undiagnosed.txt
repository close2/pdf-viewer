# Pages the oracle judges ambiguous and nobody has diagnosed.
#
# `ambiguous` is the verdict when no two reference renderers agree closely enough for
# anybody to be called wrong. It is the right thing for the ratchet to conclude and it is
# not the same as "right", so this file holds the population by name: a page leaves it by
# becoming `agrees` or by joining an AMBIGUOUS_* group in `oracle.rs` with a diagnosis
# beside it, and a page arriving in it is one that used to agree. Both directions fail the
# gate. See `undiagnosed_ambiguous` there for the argument, and the handover's §3a for the
# shape of the work.
#
# One page per line, exactly as the gate names it. Blank lines and lines beginning with `#`
# are ignored.
#
# It was empty from the three-hundred-and-seventy-ninth session, having held 754 names in
# the hundred-and-seventy-sixth, and the six-hundred-and-ninety-second refilled it — not
# because anything regressed but because the gate was given a second population to judge
# (ADR 0541). Every name below is `doc/corpora/pdfbox`, whose 143 pages no raster gate had
# ever held; the pdf.js corpus's own share of this file is still nothing.
#
# That is what the emptiness was a fact about, and it is the reason the round wrote these
# names down rather than declining to measure: a bucket kept empty by choosing the
# denominator is `CLAUDE.md`'s corpus-going-quiet failure with better bookkeeping.
#
# They are not undiagnosable, and the shape of the answer is visible from the census: 62 of
# the 63 are text at document sizes failing the differing fraction and the structural
# similarity while sitting well inside the mean and the worst tile, which is
# AMBIGUOUS_DENSE_TEXT_AT_BOOK_SIZE's and AMBIGUOUS_DENSE_TEXT_AT_PAPER_SIZE's signature.
# Saying so is a hypothesis; each of those groups is a measurement, and `doc/todo/00` is
# where the work of turning the first into the second is written down.
